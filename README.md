# CarRisk Lab

Застосунок аналізує **текст оголошення** про вживаний автомобіль за допомогою Jev AI. Показує ймовірності суперечностей та інформаційних прогалин, дві оцінки за шкалою 0–3 і категорію ризику опису. Є порівняння двох аналізів.

## Локальний запуск (без хостингу)

Потрібен Python 3. Ніяких пакетів через pip встановлювати не потрібно.

1. Відкрийте готовий файл **`local_config.py`** і впишіть ключ:

   ```python
   API_KEY = 'ваш_Jev_API_ключ'
   ```

2. У каталозі проєкту виконайте:

   ```bash
   python3 server.py
   ```

3. Відкрийте **http://127.0.0.1:8787/**, перевірте підключення та запустіть аналіз.

Зупинити сервер: `Ctrl+C`. Не відкривайте `public/index.html` через `file://` — для доступу до Jev потрібен локальний проксі.

Можна передати ключ через змінну середовища замість редагування файлу:

```bash
JEV_AI_API_KEY='ваш_Jev_API_ключ' python3 server.py
```

## Що означають показники

- **Ознаки та прогалини в описі (Noul):** для 7 перевірок відображається імовірність відповіді «Так».
- **Прозорість опису (Score, 0–3):** більше означає більше конкретної та перевірюваної інформації.
- **Потреба в додатковій перевірці (Score, 0–3):** більше означає більше підстав додатково перевіряти твердження продавця. Стандартний огляд на СТО бажаний за будь-якої оцінки.
- **Ймовірності рівнів ризику за описом оголошення (Choice):** наскільки модель схиляється до кожного з 4 варіантів оцінки **тексту**. Це не оцінка ймовірності прихованої несправності.

Чотири рівні обох числових шкал описані безпосередньо в інтерфейсі. Показники не підтверджують реальний стан автомобіля без огляду та перевірки історії.

## Структура

```text
CarRisk-Lab-v4/
├── public/
│   ├── index.html
│   ├── app.js
│   └── styles.css
├── server.py
├── local_config.py        # готовий файл для введення API-ключа
└── README.md
```

Ключ із `local_config.py` не передається браузеру; локальний сервер додає його до запитів до Jev API. Цей файл виключено з Git через `.gitignore`; перевіряйте також вміст архіву перед публікацією.

Якщо підключення не працює, перевірте API-ключ, баланс Jev та повідомлення у вікні застосунку. Документація: https://jev-ai.pro/docs
